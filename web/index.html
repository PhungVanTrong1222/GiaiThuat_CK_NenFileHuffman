TỪ FILE GỐC ĐẾN FILE NÉN

Ba bước, một kết quả.

01

Chọn dữ liệu

Thử với văn bản, CSV hoặc file log. Dữ liệu có nhiều byte lặp thường nén hiệu quả hơn.

02

Mã hóa Huffman

Byte xuất hiện nhiều được gán mã ngắn hơn. Bảng tần suất được lưu cùng dữ liệu nén.

03

Tải về và khôi phục

Nhận file .bin sau khi nén. Chọn Giải nén để khôi phục file do ShrinkIT tạo.

Lưu ý: file nhỏ hoặc dữ liệu đã nén như ZIP, JPG có thể lớn hơn sau khi nén Huffman. ShrinkIT không giải nén ZIP hay RAR.
